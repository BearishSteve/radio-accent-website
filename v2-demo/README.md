# Radio Accent v2 Demo

Minimal Vite + React + Tailwind demo for the reusable show-card system.

## Run

```bash
cd v2-demo
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The demo contains a local working copy of the show-card components for build reliability.
- The source-of-truth reusable package still exists in `../v2-show-card`.
- Demo backgrounds and host PNG placeholders live in `public/demo-assets/`.
